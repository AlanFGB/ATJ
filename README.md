ATJ - Atualização Trabalhista Judicial

O ATJ é uma plataforma de gestão e integração voltada para Fóruns Municipais. O sistema foi desenvolvido para resolver a carência de pessoal em comarcas do interior, permitindo uma comunicação direta e eficiente com o Fórum da Capital.

🚀 Funcionalidades Principais

Dashboard em Tempo Real: Visualização imediata do efetivo local e das carências registradas.

Gestão de Membros: Cadastro completo de profissionais designados, incluindo cargo e escala de horários.

Sincronização em Nuvem: Utiliza tecnologia Cloud para garantir que nenhum dado seja perdido e que as informações estejam sempre atualizadas.

Módulo de Solicitação de Vagas: Permite que o município publique necessidades de reforço diretamente para o painel estadual.

🛠️ Tecnologias Utilizadas

HTML5/CSS3 com Tailwind CSS para uma interface moderna e responsiva.

JavaScript (ES6+) para lógica de interface e controle de estado.

Firebase Firestore: Banco de dados NoSQL em nuvem para persistência e sincronização em tempo real.

Font Awesome: Iconografia técnica judicial.

📂 Como utilizar este repositório

Hospedagem: Este projeto pode ser hospedado gratuitamente via GitHub Pages.

Configuração: O arquivo principal é o gestao_forum.html. Ele contém toda a estrutura, estilos e lógica necessários.

Persistência: Os dados são salvos automaticamente vinculados à conta autenticada no módulo Firebase.

Este sistema é uma ferramenta de apoio à organização judiciária municipal e integração de recursos humanos no setor público.
